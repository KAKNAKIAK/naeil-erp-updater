프로그램 개요

Naeil ERP Fare Updater는 내일투어 ERP 시스템(erp.naeiltour.co.kr)에서 항공요금을 엑셀 연동 및 셀 직접 편집 방식을 통해 대량으로 자동 입력·저장하는 RPA 업무 자동화 프로그램입니다.

기존 수작업으로 조회하고 클릭하며 반복했던 요금 등록 단계를 간소화하고, 자릿수 튀는 문제나 이전 날짜 잔상 로딩 버그 등을 RPA 안전 로직을 통해 완벽하게 제어합니다.

🌐

디버깅 크롬 기동 & 로그인

RPA가 브라우저에 임의로 직접 계정을 기입해 접근하는 대신, 보안 세션 유지를 위해 사용자가 직접 로그인한 디버깅 브라우저 창의 제어권을 가져오는 방식으로 작동합니다.

⚠️
중요: 일반 크롬 브라우저 사전 종료
프로그램을 켜기 전에 반드시 PC에 열려 있는 모든 일반 크롬 브라우저 창을 닫아주셔야 합니다. 그렇지 않으면 디버깅 포트(9222) 점유 오류가 발생하여 프로그램이 브라우저에 접속하지 못합니다.
  • 1
    프로그램 우상단 메인 헤더에 위치한 `ERP 켜기` 버튼을 클릭합니다.
  • 2
    자동으로 포트 9222 디버깅 모드로 세팅된 새 크롬 창이 뜨면서 내일투어 ERP 로그인 화면이 로드됩니다.
  • 3
    새로 뜬 크롬 창에서 사원 아이디로 직접 로그인을 완료한 뒤, 요금을 관리 및 대입하고자 하는 ERP 해당 메뉴 요금 화면까지 이동합니다.
📁

요금 준비 & 스프레드 편집

업데이트하려는 날짜와 항목별 요금 정보는 엑셀 파일을 가져오거나, 프로그램 내에 내장된 스프레드시트(셀) 그리드 편집기를 이용해 직접 작성할 수 있습니다.

📥 엑셀 불러오기 방식
상단 엑셀 양식 다운받기 ↗ 버튼을 클릭해 8컬럼 템플릿(날짜, 항공비, 호텔비, 지상비, 여행경비, 알선수익, 소아요금, 유아요금)을 다운받아 기입한 후, 엑셀 불러오기 버튼으로 데이터만 셀에 얹어 진행합니다.
🔄 구버전 3열 포맷 호환
기존 v1 버전용 3개 열(날짜, 항공비, 알선수익) 형태의 엑셀도 그대로 가져올 수 있습니다. 이 경우 사용되지 않는 나머지 요금 셀(호텔비, 지상비 등)은 자동으로 0으로 채워져 충돌 없이 동작합니다.
그림 2. 요금 직접 입력하기 활성화 화면 (셀 편집 모드)
💡
꿀팁: 스프레드시트 편집 팁
1. 수식 자동 입력 (Fill-down): 셀에 수식을 기입하고(예: =A2+10000) 해당 셀 우하단을 더블클릭하면 엑셀처럼 아래 행에 일괄 채워집니다.
2. 실행취소(Ctrl+Z) / 다시실행(Ctrl+Y): 작업을 잘못 기입했거나 수식을 채웠을 때 툴바나 단축키로 온전하게 복구할 수 있습니다.
버튼명 설명 주요 기능 및 동작
전체 지우기 표 데이터 청소 스프레드시트 내에 기입된 날짜 및 요금 전체 데이터를 초기화합니다.
실행취소 / 다시실행 작업 히스토리 복구 수식 입력 또는 데이터 셀 기입 오류 시 전후 단계로 온전히 롤백합니다.
엑셀로 다운받기 자체 내역 내보내기 현재 그리드에 연산 완료되어 표시되고 있는 요금 전건을 엑셀 파일(.xlsx)로 내보냅니다.
🚀

RPA 실행 & 필터링

요금 준비와 ERP 로그인까지 확인되었다면 필터를 이용해 작업 대상 날짜를 타겟한 후 RPA 구동을 진행합니다.

  • 1
    날짜 필터 모드 선택:
    - 전체 대상: 그리드에 기입된 데이터 전량을 순차적으로 업데이트합니다.
    - 특정일 이후: 시작 날짜를 지정하여 해당 일자 포함 이후의 날짜만 골라 실행합니다.
    - 특정 날짜 지정: 대입하기 원하는 개별 날짜들을 콤마(,)로 구분하여 기입해 처리합니다.
  • 2
    요금수정 시작 버튼 클릭:
    클릭 시 귀여운 카카오 여행 가방 로딩 GIF 애니메이션("ERP에 연결하고 있어요...")이 등장하며 브라우저 세션에 안전하게 진입을 준비합니다.
  • 3
    실시간 작업 진행 및 중단 제어:
    - 진행 상황은 하단 실시간 작업 내용을 통해 처리 성공 및 경고 오류 메시지로 즉시 확인 가능합니다.
    - 진행 도중 필요할 경우 일시 중지 / 다시 시작 혹은 중지 버튼으로 세션을 안전하게 종료시킵니다.
🔒

이중 안전장치 기능

금액 단위가 크고 중요한 ERP 항공 요금 특성상, RPA 오작동으로 인한 잘못된 저장을 방지하기 위한 이중 검증 구조가 내장되어 있습니다.

✍️ 자릿수 어긋남 원천 방지 (JS Value Direct Injection)
ERP 금액 필드의 천 단위 실시간 콤마(,) 포맷 포커스 오류를 방지하기 위해, 한 글자씩 타이핑하는 방식 대신 금액 전체 수치를 자바스크립트 명령으로 다이렉트 주입합니다.
🔍 저장 직전 값 불일치 이중 검증
RPA가 요금을 다 입력한 뒤 저장 버튼을 누르기 바로 직전, 팝업 내의 실제 텍스트값을 역으로 읽어들여 엑셀의 목표가와 숫자 대 숫자 검증을 수행합니다. 다르면 저장을 차단하고 모달을 닫습니다.

FAQ / 트러블슈팅

프로그램을 사용하면서 발생할 수 있는 주요 예외 메시지와 처리 방안입니다.

프로그램이 윈도우 뮤텍스로 중복 차단되어 있거나, 일반 크롬 창이 실행 중일 때 발생합니다. 작업 표시줄 우측 하단의 트레이 아이콘이나 작업 관리자(Ctrl + Shift + Esc)에서 기존에 켜두신 Chrome 관련 프로세스를 강제 종료하고, 프로그램 우측 헤더의 ERP 켜기를 이용해 다시 시작해 주세요.

가져온 엑셀에 공백이 있거나, 숫자 대신 문자(예: "요금미정") 혹은 음수가 들어간 행이 존재하는 경우 발생합니다. 해당 행은 강제로 0원 처리되어 ERP 팝업에 입력 및 안전 통과가 유지됩니다. 엑셀 요금 열의 빈 칸 유무를 정돈해 주세요.

초기 v2.0.1 셋업 릴리즈 버전을 수동 설치하신 경우 내부에 자동 업데이트 모듈 런타임이 예외 누락되어 있을 수 있습니다. 이번 1회만 공식 배포용 최신 실행파일(예: ERP 항공요금수정_배포용_v2.0.3.exe)을 받아 덮어씌워 주시면 이후 버전부터 정상 반영됩니다.

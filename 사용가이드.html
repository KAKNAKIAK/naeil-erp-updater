프로그램 개요

📌
가이드 적용 버전: v5.0.18
이 사용 가이드는 Naeil ERP Fare Updater v5.0.18 최신 정식 버전을 기준으로 작성되었습니다.

Naeil ERP Fare Updater는 내일투어 ERP 시스템(erp.naeiltour.co.kr)의 행사요금일괄수정 화면에서 항공요금을 엑셀 연동 및 셀 직접 편집 방식으로 자동 입력·저장하고, 별도 TOPAS 요금조회 탭에서 출발편·귀국편 조회내용으로 박수별 왕복요금까지 계산하는 RPA 업무 자동화 프로그램입니다.

날짜마다 조회하고 클릭해서 요금을 하나하나 입력하던 과정, TOPAS 다음날 조회 반복, 운임/시즌 기준 요금 계산, ERP 입력표 전달까지 이어지는 반복 작업을 줄여 줍니다.

브라우저 켜기 & 로그인

프로그램이 직접 로그인하지 않고, 사용자가 직접 로그인한 크롬 창을 그대로 이어받아 작동합니다. 그래서 계정 정보가 프로그램에 저장되지 않아 안전합니다.

⚠️
중요: 일반 크롬 브라우저 사전 종료
프로그램을 켜기 전에 PC에 열려 있는 크롬 창을 모두 닫아 주세요. 크롬 창이 켜져 있으면 프로그램이 ERP에 제대로 연결되지 않습니다.
  • 1
    프로그램 우상단 메인 헤더에 위치한 브라우저 켜기 버튼을 클릭합니다. 선택된 탭에 따라 요금수정 탭에서는 ERP 로그인 화면, 토파스 요금조회 탭에서는 TOPAS 로그인 화면이 열립니다.
  • 2
    새 크롬 창이 자동으로 열리면서 내일투어 ERP 로그인 화면이 나타납니다.
  • 3
    새로 뜬 크롬 창에서 사원 아이디로 직접 로그인을 완료한 뒤, 해외상품 → 행사요금일괄수정 화면까지 이동합니다.
⚠️
중요: RPA는 [행사요금일괄수정] 화면에서 동작합니다
요금수정을 시작하기 전, ERP가 행사요금일괄수정 화면에 열려 있어야 합니다. RPA는 이 화면의 출발일자 검색칸에 날짜를 넣고 조회 → 전체 선택 → 요금 입력 → 저장을 자동으로 반복합니다. 다른 화면에 있으면 입력 필드를 찾지 못해 작업이 진행되지 않습니다.
📁

요금 준비 & 스프레드 편집

업데이트하려는 날짜와 항목별 요금 정보는 엑셀 파일을 가져오거나, 프로그램 내에 내장된 스프레드시트(셀) 그리드 편집기를 이용해 직접 작성할 수 있습니다.

📥 엑셀 양식 다운받기 & 요금불러오기
상단 엑셀 양식 다운받기 ↗ 버튼을 누르면 양식 선택창이 떠서 단일 날짜 양식(8열: 날짜, 항공비, 호텔비, 지상비, 여행경비, 알선수익, 소아요금, 유아요금)과 기간 입력 양식(시작일·종료일이 나뉜 9열) 중 하나를 고를 수 있습니다. 받은 양식에 요금을 채운 뒤 요금불러오기 버튼으로 데이터를 표에 얹으면 되고, 파일이 단일인지 기간인지는 자동으로 인식해 표를 맞춰 줍니다.
그림 2. 엑셀 양식 다운받기 ↗ 클릭 시 뜨는 양식 선택창 — 단일/기간을 고르고 다운받기를 누릅니다.
🗓️ 단일 날짜 입력 (기본)
하루(또는 날짜별)로 요금을 적는 기본 방식입니다. 입력표가 8열(날짜 + 요금 7종)로 표시됩니다. 기존 v1 버전용 3개 열(날짜, 항공비, 알선수익) 엑셀도 그대로 불러올 수 있고, 비어 있는 나머지 요금 칸은 자동으로 0으로 채워집니다.
그림 3. 단일 날짜 입력 — 우측 입력표가 8열(날짜 + 요금 7종)로 표시됩니다.
🗓️ 기간 입력 (시작일/종료일 분리)
같은 요금이 며칠씩 이어질 때 유용합니다. 입력표 위쪽 시작일/종료일 분리 (기간 입력) 체크박스를 켜면 표가 9열로 바뀌어 시작일과 종료일을 따로 적을 수 있고, RPA가 그 구간을 한 번에 조회해 일괄 수정합니다. 체크를 풀면 다시 단일 날짜(8열) 표로 돌아갑니다.
그림 4. 기간 입력 — 시작일/종료일 분리 (기간 입력) 체크박스를 켜면 표가 9열(시작일·종료일 분리)로 바뀝니다.
💡
꿀팁: 스프레드시트 편집 팁
1. 일반 값 전체 채우기: 요금 칸에 입력한 숫자·텍스트 값을 더블클릭하면 확인창 후 데이터가 있는 마지막 행까지 같은 값으로 채웁니다. 기존 수식도 일반 값으로 바뀝니다.
2. 수식 자동 입력 (Fill-down): 셀에 수식을 기입하고(예: =A2+10000) 더블클릭하면 아래 행까지 채워지며, 각 행의 같은 줄 값을 기준으로 계산됩니다. 날짜 칸은 전체 채우기 대상에서 제외됩니다.
3. 실행취소(Ctrl+Z) / 다시실행(Ctrl+Y): 셀 편집·수식·행 변경·엑셀 불러오기·TOPAS 결과 전달 등 입력표 작업을 툴바 또는 단축키로 되돌리거나 다시 적용할 수 있습니다.
📋 진행구분 텍스트와 호텔비 수정 규칙
별도 진행구분 칸이 없어도 요금 칸에 진행구분 텍스트를 입력하면 요금 0원으로 저장하지 않고 ERP 상태 변경으로 처리합니다. 대기예약은 대기예약, 대기 예약, 예약대기, 예약 대기 네 가지 표현을 모두 같은 상태로 인식하며, 예약신청과 예약마감도 인식합니다. 호텔비 금액이 하나라도 있으면 입력표의 진행구분 텍스트와 관계없이, ERP에서 대기예약(06) 행만 먼저 예약신청(04)으로 변경한 뒤 호텔비를 수정합니다. 기존 예약신청·팀출발 등 다른 진행구분은 그대로 유지되고, 예약마감 행은 상태 변경과 요금 수정에서 제외됩니다. 대기예약에서 변경된 행의 최종 상태는 예약신청으로 유지됩니다.
➕ 작업 목록에 추가 · 다중 상품 작업
입력표와 조건을 준비한 뒤 작업 목록에 추가를 누르면 현재 작업을 큐에 등록할 수 있습니다. 작업 목록은 여러 상품을 함께 보관하며, 작업별 조건·진행상황·건수를 확인하면서 순서대로 실행합니다. 선택한 작업은 입력표로 불러오기로 다시 편집하거나 위로/아래로로 실행 순서를 바꿀 수 있으며, 불필요한 항목은 선택 삭제 또는 목록 비우기로 정돈합니다. 작업을 추가하려면 요금구분·항공사코드·출발편·호텔명 중 하나 이상이 있어야 합니다.
📊 조건열이 있는 엑셀은 작업 목록으로 자동 분리
엑셀에 요금구분과 항공사코드 열이 함께 있으면 조건열 엑셀로 인식합니다. 출발편, 호텔명, 진행구분 열은 선택적으로 추가할 수 있으며, 같은 조건 조합의 날짜 행을 하나의 작업으로 묶어 작업 목록에 자동 등록합니다. 기존처럼 조건열이 없는 일반 엑셀은 입력표로 불러옵니다. 조건열의 요금구분과 항공사코드는 각 행에 정확히 입력해야 합니다.
버튼명 설명 주요 기능 및 동작
전체 지우기 표 데이터 청소 스프레드시트 내에 기입된 날짜 및 요금 전체 데이터를 초기화합니다.
실행취소 / 다시실행 작업 히스토리 복구 수식 입력 또는 데이터 셀 기입 오류 시 전후 단계로 온전히 롤백합니다.
요금구간 병합 연속 날짜 정리 같은 요금이 이어지는 날짜를 시작일·종료일 구간으로 합칩니다. 중간에 비는 날짜가 있으면 별도 구간으로 분리합니다.
항공사코드 ERP 조회 조건 ERP 화면의 항공사코드 목록을 읽어 오며, 선택한 코드를 요금수정 조회 조건에 함께 전달합니다.
작업 목록에 추가 다중 상품 큐 등록 현재 입력표와 검색 조건을 하나의 작업으로 등록합니다. 등록된 작업은 입력표로 다시 불러와 편집하거나 순서를 바꾸고 삭제할 수 있습니다.
엑셀로 다운받기 자체 내역 내보내기 현재 그리드에 연산 완료되어 표시되고 있는 요금 전건을 엑셀 파일(.xlsx)로 내보냅니다.
🚀

RPA 실행 & 필터링

요금 준비와 ERP 로그인까지 확인되었다면 검색 조건과 날짜 필터로 작업 대상을 좁힌 후 RPA 구동을 진행합니다. 작업 목록에 여러 상품을 등록했다면 등록 순서대로 각 상품의 조건을 ERP에 적용해 처리합니다.

🔎 ERP 검색 조건 4가지
항공사코드, 요금구분, 출발편, 호텔명 검색 조건을 함께 사용할 수 있습니다. 항공사코드는 ERP에서 읽어온 드롭다운 목록에서 선택해야 안전합니다. 요금구분은 ERP에 저장된 문자열을 그대로 입력해야 하므로 3박_다낭과 3박 다낭을 바꾸어 입력하지 마세요. 출발편도 ERP 화면에 표시되는 편명·기호를 확인해 그대로 입력해야 하며, 임의의 공백이나 다른 표기로 바꾸면 조회 결과가 달라질 수 있습니다. 호텔명은 검색어를 입력한 뒤 아래 나타나는 ERP 검색 결과에서 정확한 호텔을 선택해 지정하는 것을 권합니다. 비슷한 이름의 호텔을 직접 텍스트로 기입하면 엉뚱한 상품이 조회되는 실수를 막을 수 있습니다.
💡
단일 입력표 실행 시 ERP 화면 조건 가져오기
단일 입력표 실행에서 프로그램 조건이 비어 있고 ERP 화면에 조건이 있으면 확인창이 나타날 수 있습니다. 예는 ERP 화면의 조건을 가져와 실행, 아니오는 프로그램에 입력한 조건 그대로 실행, 취소는 실행하지 않고 입력 화면으로 돌아가는 의미입니다. 취소를 누르면 RPA가 시작되지 않습니다.
  • 1
    날짜 필터 모드 선택:
    - 전체 대상: 그리드에 기입된 데이터 전량을 순차적으로 업데이트합니다.
    - 특정일 이후: 시작 날짜를 지정하여 해당 일자 포함 이후의 날짜만 골라 실행합니다.
    - 특정 날짜 지정: 대입하기 원하는 개별 날짜들을 콤마(,)로 구분하여 기입해 처리합니다.
    - 기간 범위 지정: 시작일과 종료일을 정해 그 사이에 걸치는 행만 골라 실행합니다.
    ※ 기간 입력 모드에서는 각 행의 시작일~종료일 구간이 필터 범위와 겹치기만 해도 대상에 포함됩니다.
  • 2
    요금수정 시작 버튼 클릭:
    클릭하면 "ERP에 연결하고 있어요..." 로딩 화면이 잠깐 표시되면서 작업을 준비합니다. 작업 목록이 있으면 각 작업의 항공사코드·요금구분·출발편·호텔명 조건을 차례로 적용하며, 단일 실행에서 조건 가져오기 확인창이 나오면 위의 예/아니오/취소 의미를 확인합니다.
  • 3
    실시간 작업 진행 및 중단 제어:
    - 진행 상황은 하단 실시간 작업 내용을 통해 처리 성공 및 경고 오류 메시지로 즉시 확인 가능합니다.
    - 진행 도중 필요하면 일시 중지 / 다시 시작 또는 중지 버튼으로 작업을 멈출 수 있습니다.
그림 5. 기간 범위 지정을 고르면 시작일·종료일 입력칸이 나타납니다.

TOPAS 요금조회

토파스 요금조회 탭은 TOPAS SellConnect Entry 화면에서 출발편과 귀국편 조회내용을 각각 가져온 뒤, 항공노선·박수를 기준으로 출발일별 왕복요금을 계산합니다. 계산 결과는 복사, 엑셀 다운로드, 계산 과정 확인, ERP 요금 입력표 전달까지 이어집니다.

⚠️
출발편과 귀국편 첫 조회는 사용자가 직접 실행합니다
예를 들어 TOPAS Entry 화면에서 AN20JULDADICN/AZE594처럼 첫 날짜 조회를 먼저 실행해 결과가 표시된 상태에서 시작합니다. 출발편을 먼저 가져오고, 같은 방식으로 귀국편도 가져오면 됩니다.
그림 6. 토파스 요금조회 탭 — 출발편·귀국편 조회내용이 들어오면 조회 기간, 항공노선, 박수, 준비 상태를 한 화면에서 확인합니다.
  • 1
    토파스 요금조회 탭 선택:
    화면 상단의 토파스 요금조회 탭을 선택합니다. 상단에는 AC1 자동반복과 진행률, 가운데에는 출발편·귀국편 조회내용 칸, 아래에는 항공노선·박수·요금 결과 영역이 표시됩니다.
  • 2
    브라우저 켜기:
    브라우저 켜기 버튼을 눌러 TOPAS 로그인 화면을 열고, 사용자가 직접 로그인합니다.
  • 3
    출발편 첫 날짜 조회:
    TOPAS Entry 화면에서 출발편 첫 조회 명령을 직접 입력하고 결과가 화면에 표시될 때까지 기다립니다. 조회하려는 노선/편명/날짜가 맞는지 확인한 뒤 진행하세요.
그림 7. TOPAS Entry 첫 조회 예시 — 조회 결과가 화면에 표시되고 마지막 프롬프트가 >로 돌아온 상태에서 프로그램을 실행하는 것이 가장 안정적입니다.
  • 4
    출발편 AC1 자동반복:
    프로그램의 AC1 자동반복 버튼을 누르면 조회 횟수 입력창이 뜹니다. 필요한 날짜 수만큼 숫자를 입력하면 출발편 조회내용이 채워집니다.
그림 8. AC1 실행 횟수 입력 — 숫자만 입력합니다. 200은 예시일 뿐이며 필요한 날짜 수만큼 입력하면 됩니다.
  • 5
    귀국편 조회내용 수집:
    TOPAS 화면에서 귀국편 첫 날짜를 직접 조회한 뒤 다시 AC1 자동반복을 실행합니다. 조회가 끝나면 귀국편 조회내용이 채워집니다.
  • 6
    운임/시즌 상태 확인:
    요금 계산 전 우측의 운임/시즌 상태가 준비되었는지 확인합니다. 데이터는 캐시가 사용될 수 있으므로 최신 운임·시즌 기준이 필요하거나 기준 데이터가 바뀐 경우 ↻ 버튼으로 새로고침한 뒤 상태가 준비됨으로 바뀐 것을 확인하세요. 로드 실패 또는 미로드 상태에서는 요금 계산을 실행하지 않습니다.
  • 7
    항공노선·박수 선택 후 요금 조회:
    항공노선이 자동으로 채워지지 않으면 항공노선 칸에 직접 입력합니다. 박수는 2박·3박·4박·5박 또는 직접 입력 후 +추가로 선택하고, 요금 조회를 눌러 왕복요금을 계산합니다.
그림 9. TOPAS 조회 진행 화면 — 요청한 횟수와 완료된 횟수를 확인하고, 필요하면 중지로 현재 수집을 멈춥니다.
그림 10. TOPAS 조회내용 팝업 — 가져온 조회내용을 확인하고 전체 복사하기로 한 번에 복사합니다.
  • 8
    계산 결과 확인 및 ERP 입력표 전달:
    결과 탭에는 출발일, 왕복요금, 상태가 표시됩니다. 계산 과정 보기로 근거를 확인하고, 엑셀 다운로드로 저장하거나 복사로 결과를 클립보드에 담을 수 있습니다. 요금수정 보내기를 누르면 마감이 아닌 행만 ERP 요금 입력표로 전달되며, 이때 노선에서 판단한 항공사코드도 함께 반영됩니다. 마감으로 제외된 행은 별도 팝업에서 출발일·귀국일·박수 목록을 확인하고 복사할 수 있습니다.
그림 11. 요금 조회 결과 — 출발일별 왕복요금과 마감 상태를 확인하고, 계산 과정 보기, 엑셀 다운로드, 요금수정 보내기, 복사를 실행합니다.
그림 12. 계산 과정 팝업 — 출발편·귀국편 요금과 박수별 계산 근거를 확인할 수 있습니다.
그림 13. 마감 제외 팝업 — ERP 입력표로 보내지 않은 마감 행의 출발일, 귀국일, 박수를 확인하고 복사합니다.
그림 14. 요금수정 입력표 전달 — 마감이 아닌 행만 항공비 칸에 들어가며, 출처 배지와 항공사코드가 함께 표시됩니다.

오류가 뜰 때 확인할 것
1. 출발편과 귀국편 첫 조회를 각각 먼저 실행했는지 확인하세요.
2. 첫 조회 결과가 아직 로딩 중이면 프로그램이 조회내용을 가져오지 못할 수 있습니다. 화면 표시가 끝난 뒤 다시 실행하세요.
3. 운임/시즌 캐시가 오래되었거나 기준이 바뀌었다면 ↻로 새로고침하고 준비됨 상태를 확인하세요. 운임/시즌 미로드 상태에서는 요금 계산을 할 수 없습니다.
4. 조회가 중간에 멈추면 TOPAS 화면 상태를 확인한 뒤 다시 실행하세요.

FAQ / 트러블슈팅

프로그램을 사용하면서 발생할 수 있는 주요 예외 메시지와 처리 방안입니다.

프로그램이 이미 켜져 있거나, 일반 크롬 창이 열려 있을 때 생깁니다. 열려 있는 크롬 창을 모두 닫은 뒤 프로그램의 브라우저 켜기 버튼으로 다시 시작해 주세요. 그래도 안 되면 작업 관리자(Ctrl + Shift + Esc)에서 크롬을 모두 종료한 다음 다시 시도해 보세요.

엑셀 요금 칸이 비어 있거나, 숫자가 아닌 글자(예: "요금미정")나 음수가 들어 있을 때 나옵니다. 그 칸은 0원으로 처리해 작업이 멈추지 않고 계속 진행됩니다. 의도한 금액이 있다면 엑셀의 빈 칸이나 잘못된 값을 정리한 뒤 다시 불러와 주세요.

아주 예전 버전을 쓰고 계신 경우 자동 업데이트가 동작하지 않을 수 있습니다. 이럴 때는 최신 설치파일을 한 번만 새로 받아 설치해 주세요. 그다음부터는 새 버전이 나올 때마다 프로그램을 켤 때 자동으로 안내됩니다.

먼저 ↻ 버튼으로 캐시를 새로고침해 주세요. 상태가 준비됨으로 바뀐 뒤 요금 계산을 실행할 수 있습니다. 최신 기준이 필요한데 이전 데이터가 표시되는 경우에도 새로고침 후 다시 확인하세요. 계속 실패하면 잠시 후 다시 시도해 주세요.

네 가지 조건의 입력값을 ERP에 저장된 표기와 비교해 주세요. 특히 요금구분은 3박_다낭처럼 언더스코어·공백을 포함한 실제 텍스트를 그대로 입력해야 하며, 출발편도 ERP에 표시된 편명 그대로 입력해야 합니다. 호텔명은 검색 결과 목록에서 정확한 호텔을 선택한 뒤 다시 조회하는 것을 권장합니다. 항공사코드는 목록에서 선택하세요.

예는 ERP 화면의 요금구분·항공사코드·출발편·호텔명 조건을 가져와 실행하고, 아니오는 프로그램 입력값 그대로 실행합니다. 취소는 실행을 중단하고 입력 화면으로 돌아갑니다. 조건을 다시 확인해야 할 때는 취소 후 값을 수정하세요.

각 상품의 입력표와 조건을 준비해 작업 목록에 추가를 누르세요. 작업 목록에서 선택한 작업을 입력표로 불러오기로 편집하고, 위로/아래로로 순서를 바꾸며, 선택 삭제 또는 목록 비우기로 정리할 수 있습니다. 조건열이 있는 엑셀은 요금구분·항공사코드 조합을 기준으로 작업 목록을 자동 구성합니다.
